Troubleshooting Guide

Find solutions to common issues and get your bot running smoothly

QR Code Issues

Problem: QR Code not appearing or not scanning

  1. Refresh the page and wait 30 seconds for the QR code to load
  2. Clear your browser cache and cookies
  3. Try using a different browser (Chrome, Firefox, Safari)
  4. Ensure your WhatsApp app is updated to the latest version
  5. Make sure you're scanning with the correct WhatsApp account
  6. Try scanning from WhatsApp Web settings: Settings > Linked Devices > Link a Device

Bot Not Responding

Problem: Bot doesn't respond to commands

  1. Check if the bot status shows "Connected" in your dashboard
  2. Verify you're using the correct command format (e.g., !tagall, !help)
  3. Ensure the bot has admin privileges in the group
  4. Try sending commands in a private chat first to test connectivity
  5. Wait 2-3 minutes as there might be a temporary delay
  6. Restart the bot from your dashboard

Group Management Issues

Problem: Can't tag members or manage groups

  1. Ensure the bot is added as an admin in the WhatsApp group
  2. Check that group settings allow all members to send messages
  3. Verify the group has less than 256 members (WhatsApp limit)
  4. Make sure the bot account is not blocked by any group members
  5. Try removing and re-adding the bot to the group
  6. Check if the group description contains any restricted keywords

Connection Problems

Problem: Frequent disconnections or "Offline" status

  1. Check your internet connection stability
  2. Ensure WhatsApp Web is not open in another browser/device
  3. Close other WhatsApp Web sessions: Settings > Linked Devices
  4. Restart your router/modem
  5. Try using a VPN if you're in a restricted network
  6. Contact your ISP if the problem persists

Message Delays

Problem: Messages sent with delay or not at all

  1. Check if you've exceeded your daily message limit
  2. Verify your subscription plan allows the number of messages you're sending
  3. Reduce the frequency of automated messages
  4. Check WhatsApp's business policy compliance
  5. Ensure messages don't contain spam-like content
  6. Try sending messages manually to test connectivity

Account Restrictions

Problem: WhatsApp account temporarily banned or restricted

  1. Stop all automated activities immediately
  2. Wait 24-48 hours before attempting to use the account
  3. Review WhatsApp's Terms of Service and Business Policy
  4. Reduce message frequency and avoid spam-like behavior
  5. Use more natural, conversational message patterns
  6. Consider using multiple accounts for high-volume messaging

Dashboard Issues

Problem: Can't access dashboard or features not working

  1. Clear browser cache and cookies
  2. Disable browser extensions temporarily
  3. Try accessing from an incognito/private browser window
  4. Check if JavaScript is enabled in your browser
  5. Try a different browser or device
  6. Verify your account subscription is active

Still Need Help?

If none of the above solutions work, our support team is here to help you get back on track.
